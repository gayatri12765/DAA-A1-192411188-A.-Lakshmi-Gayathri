DAA Assignment 3 Python Programs (CO3)

Files
- daa_algorithms.py: reusable implementations for Q1-Q7.
- q1_ordered_data.py: pairwise maximum/minimum and binary search.
- q2_sorting.py: Merge Sort and instrumented Quick Sort.
- q3_karatsuba.py: Karatsuba integer multiplication.
- q4_strassen.py: conventional and Strassen matrix multiplication.
- q5_closest_pair.py: divide-and-conquer closest pair in the plane.
- q6_selection_subset_sum.py: QuickSelect, Median of Medians, and Meet-in-the-Middle subset sum.
- q7_inversion_count.py: model divide-and-conquer design challenge using inversion counting.

Run
1. Extract this ZIP file.
2. Open a terminal in the extracted folder.
3. Run a program with Python 3, for example:
   python q1_ordered_data.py
   python q2_sorting.py
   python q3_karatsuba.py
   python q4_strassen.py
   python q5_closest_pair.py
   python q6_selection_subset_sum.py
   python q7_inversion_count.py

The programs use only the Python standard library. They print example outputs and provide reusable functions. For experiments, change input sizes and record output from your own computer. Do not report timing values until you run the programs on the target machine. Q7 is a worked example because the assignment itself leaves the design-challenge problem open; the pair should complete its own independent proposal and collaboration record.
